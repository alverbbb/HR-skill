# HR-skill

## jd-builder：招聘需求与 JD 整理

将 JD 原文或零散用人需求整理为岗位职责、能力要求、招聘关键词，以及必须项、加分项和可培养项。技能会标注信息缺口和待确认事项，适合 HRBP 招聘沟通。

## resume-tagger：简历事实提取

从简历中整理工作年限、工作履历、项目经历、技能证据和信息缺口，保留原文依据及未验证状态，不进行岗位匹配或筛选。技能内容可在 [resume-tagger/SKILL.md](resume-tagger/SKILL.md) 查看和编辑。

## 在 Codex 中安装

在自己的 Codex 对话中发送：

> 请从 https://github.com/alverbbb/HR-skill/tree/main/jd-builder 安装 jd-builder 技能。

安装 resume-tagger 时，在 Codex 对话中发送：

> 请从 https://github.com/alverbbb/HR-skill/tree/main/resume-tagger 安装 resume-tagger 技能。

安装后，在下一轮对话中即可使用。例如：

> 使用 jd-builder 整理以下招聘需求，列出岗位职责、能力要求、关键词、必须项、加分项和可培养项；缺失信息请标注待确认。  
> （在此粘贴招聘需求）

使用 resume-tagger 的示例：

> 使用 resume-tagger 整理以下简历，提取工作年限、项目经历、技能证据和信息缺口，并标明原文依据。请勿进行岗位匹配或筛选。
