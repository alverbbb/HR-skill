# HR-skill

## jd-builder：招聘需求与 JD 整理

将 JD 原文或零散用人需求整理为岗位职责、能力要求、招聘关键词，以及必须项、加分项和可培养项。技能会标注信息缺口和待确认事项，适合 HRBP 招聘沟通。

## 在 Codex 中安装

在自己的 Codex 对话中发送：

> 请从 https://github.com/alverbbb/HR-skill/tree/main/jd-builder 安装 jd-builder 技能。

安装后，在下一轮对话中即可使用。例如：

> 使用 jd-builder 整理以下招聘需求，列出岗位职责、能力要求、关键词、必须项、加分项和可培养项；缺失信息请标注待确认。  
> （在此粘贴招聘需求）

## 下载

也可以[下载整个仓库的 ZIP](https://github.com/alverbbb/HR-skill/archive/refs/heads/main.zip)，解压后找到 `jd-builder/SKILL.md`。ZIP 便于保存和分享，但下载并解压本身不会自动安装技能；在 Codex 中使用上述安装提示即可。

技能内容可在 [jd-builder/SKILL.md](jd-builder/SKILL.md) 查看和编辑。
