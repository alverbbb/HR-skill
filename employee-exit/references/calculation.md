# 测算工作表

输入：主体、所在地及合同履行地、关系类型、起始与拟终止日期、连续工龄及关联单位变更证明、2008年前后各段、既往已支付补偿；发起方及合法路径；前12个月逐月应得工资和奖金津贴明细、实际工作月数、上月工资、当地最低工资和适用年份官方三倍统计基数及来源、年假已休与工资、独立应付项目、是否保护及争议。明确税前／税后、时间口径与证据，未知留空。

1. 确认法定补偿适用：按本单位依法计入的年限，满一年计1个月；剩余六个月以上不满一年计1个月，不满六个月计0.5个月。日期、折算及特殊中断或调动的口径不明交法务，列明算式。跨2008年按第97条、当时地方规则及事由分段判断适用年限和标准，避免统一公式；特殊工龄与既付补偿同样复核。
2. 基数：解除或终止前12个月应得工资总额÷12；不足12个月按实际工作月数。含计时计件工资、奖金、津贴补贴等货币性收入；低于当地最低工资依法按最低工资。平均工资高于适用的所在直辖市或设区市上年度职工月平均工资三倍时，按三倍计算且支付年限最高12年；并非所有人都封顶。三倍口径和跨期分段的适用要核验，不能误用社保缴费基数。
3. 经济补偿 N = 已核准补偿月数 × 已核准基数。第40条满足全部条件时，单位选提前30日书面通知或额外支付一个月工资；选后者时额外工资按上月工资标准核算，不必等于N基数。其他场景不自动加1。
4. 违法解除或终止时，先核继续履行请求及可能性；依第87条应付赔偿时，按依法算出的经济补偿标准×2。第25条规定支付赔偿金不再支付经济补偿，列为替代情景，不能同一解除重复相加；具体跨期口径由当地法务核准。协商额由双方自愿商议，单列是否含法定补偿及范围，不能称为法定数额或用最低金额策略规避权益。
5. 工资、加班费、奖金／佣金、未休年假、社保公积金、报销及其他约定款项分别核对权利、期间、已支付和余额，不擅自抵扣。年假当年折算、历史年假、日工资及300%中已付正常工资部分依现行规则及地方口径核算，避免重复；社保公积金按规定核缴和接续，不能当作协商筹码。税费与支付日另核。

输出表：情景｜依据及条件｜年限分段与月数｜工资明细及基数｜公式｜结果／待核实｜独立结算｜已付及抵扣依据｜来源与日期｜审批。各情景分别合计，未知值不以零代替；避免将 2N 与 N 同时合计。

示例仅为假设：2008年后入职、可计年限3年4个月、前12个月应得工资均为10,000元，假定当地最低标准和三倍门槛均不改变该基数，且无特殊工龄。月数=3+0.5=3.5，N=35,000元。若第40条条件成立且选择额外支付、上月工资10,000元，情景为35,000+10,000=45,000元；若另一个违法解除情景经确认应付赔偿，2N=70,000元，替代N而非105,000元。工资、年假等尚未提供，不能计算总结算。此示例不证明任何具体案件适用；地方数值和事实均待核实。
