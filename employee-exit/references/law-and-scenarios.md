## 场景矩阵

| 场景 | 先核查 | 路径与风险 |
|---|---|---|
| 员工主动离职 | 意愿是否真实、通知、被迫离职事由、挽留意愿 | 可讨论留任但尊重选择；第38条等导致员工解除可能有补偿，勿一概认定为零 |
| 协商解除 | 谁首先提出、双方自愿、有效方案与审批 | 第36条协商一致；单位提出且一致，通常依第46条支付经济补偿；员工提出的法定补偿需按事实与适用规定核验，不预断；附加金额仅为建议 |
| 固定期限到期 | 续订条件、意愿、续订次数、保护及顺延 | 第44、45、46条与续订权利，不能仅凭到期自动结论 |
| 试用期 | 合同、合法试用期、录用条件、证明和程序 | 试用期并非随意解除；39条不符合录用条件须有证明；其他事由另核 |
| 绩效 | 标准、证据、反馈、培训或调岗及其后表现 | 不胜任不等于低绩效；第40条第2项所有条件和通知程序均需核验 |
| 违纪 | 制度合法性、公示、行为、严重程度、证据和程序 | 第39条条件须证明；禁止预设违纪成立 |
| 客观情况重大变化 | 变化、无法履行、变更协商及结果 | 第40条第3项具体构成及程序待法务核查，经营调整不当然成立 |
| 经济性裁员 | 法定事由、规模、人员范围、优先留用、意见与报告 | 第41条程序和保护须逐项核查，群体方案先法务审批 |
| 拒签／异议／仲裁 | 真实意见、争议点、时效、送达与证据保全 | 拒签不是同意或自行离职；尊重申诉与仲裁权，法务核查时效，不得报复 |

决策树：身份与适用地不明→补充；存在安全紧急情况→先安全应急；保护或重大争议→法务审查；员工主动离职→核真实意思、38条及留任；双方协商→确认发起方、独立权利与自愿；拟单方解除／终止→核具体事由、保护、证据、程序及续订／顺延→有任何缺口暂停执行；批准后沟通并依法交接结算。

红旗：要求员工写辞职掩盖单位发起、口头承诺代替书面核查、缺证据先定性、孕产／医疗期等一概可裁、签字作为支付工资或社保前提、以仲裁威胁报复、未经核实强制限时或只展示单一低金额、未经审批通知或发送协议。劳务派遣、非全日制、退休返聘、跨地区、工伤待遇、竞业及涉外另核，不套普通模型。
